# OHT Animation

An Overhead Hoist Transport (OHT) animation for **NVIDIA Isaac Sim 6.0**. The OHT picks a magazine up from **one machine**, drives around the rail loop, and places it on **another machine**.


## What it does

1. OHT drive along the track towards one machine
2. Lower the hoist, close the claws, lift the magazine
3. Drive along the rail loop towards another machine
4. Lower the hoist, release the magazine, lift the hoist
